# 2000 天 · 手机制作上传包

下载本分支中的 `phone-maker-upload.zip`，解压后得到 `website` 文件夹。

1. 在电脑上登录 https://app.netlify.com/drop 。
2. 把整个 `website` 文件夹拖进上传区。
3. 上传成功后，首页给对方打开；同一网址后加 `/make.html` 是手机制作入口。
4. 手机制作时使用 Safari 或 Chrome。制作后导出 `index.html`，回到托管平台替换首页。

包内已包含用户提供的《两只恋人》完整音乐，以及网页交互。部分手机会要求首次触摸后才能播放音乐。

本分支只用于交付，不改动项目主分支。网页尚未部署到托管服务。
