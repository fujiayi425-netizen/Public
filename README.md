# 照片弹窗编辑 · 制作页修补包

下载 `maker-photo-edit-fix.zip` 并解压。用其中的 `make.html` 替换原 `website/make.html`，保留文件夹里最新的 `index.html`，然后将整个 `website` 文件夹上传到现有 Netlify 站点的 Deploys 页面。

制作入口：https://clever-valkyrie-48b938.netlify.app/make.html

更新后，旋转木马照片弹窗内可直接编辑标题、日期、地点与回忆，并添加或更换照片。空白回忆也可先写文字，之后补图不会覆盖文字。与制作首页表单同步，导出后保留。

本包仅交付制作页修补文件，Netlify 站点仍需站点所有者上传更新；同一浏览器和网址可继续使用此前成功保存的草稿。
